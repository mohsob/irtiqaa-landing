أكاديمية ارتقاء — تحديث الأيقونات
تم استبدال الرموز السابقة غير المناسبة بأيقونات SVG عربية/تعليمية احترافية:
- التربية الإيمانية: مسجد.
- التجويد: مصحف/كتاب مفتوح.
- التحفيظ: مصحف.
- المميزات: معلمات، تقويم، متابعة، أمان.
- البرامج: قيم/تربية إيمانية، تجويد، تحفيظ.
جميع الأيقونات بنفس الهوية الذهبية وبأسلوب Line Icon متناسق.
